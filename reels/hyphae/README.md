# Hyphae

**Substrate** · a mycelium closing its own loops

<img src="loop.webp" width="320" align="right">

> *A tree branches. A fungus branches back.*

A hypha only ever extends at its tip. It wanders, it splits in two, and when it
runs into another hypha it **fuses with it and stops**.

That fusion — anastomosis — is the whole difference between a fungus and a
tree. A tree's branches diverge and never meet again, so a tree is a tree in the
graph-theoretic sense too: no loops, one path between any two points. A mycelium
has loops. It can route around damage, and it can move material between distant
points by more than one road. The network is not a by-product of growing; it is
what the growing is for.

Tips also turn away from ground already colonised, which is the cheapest honest
stand-in for growing down a nutrient gradient — the substrate behind the front
is spent. The colony is bounded like a plate culture and the clip ends when
every tip has either fused or reached the rim, so the last frame is where the
process actually stops rather than where the clock ran out.

```
fungal mycelium
extend · branch · anastomose
fusion makes a network, not a tree
```
